# cablegram-mcp

Raw dispatches from tech, AI and Chinese/Russian sources — filtered by date, never ranked.

A *cablegram* was the unedited message that arrived over the submarine cables, before an
editor turned it into a story. This server is the cable: it brings the dispatches. Your
model is the editor.

Nineteen sources in English, Chinese and Russian. Headlines are never translated: each
dispatch carries its language, and the model reading it has more context for that than any
translation step would.

Status: early development.
